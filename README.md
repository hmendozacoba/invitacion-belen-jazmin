# Invitación digital · Belén Jazmín

Sitio estático en HTML, CSS y JavaScript, preparado para publicar con GitHub Pages.

## Diseño
- Portada moderna con la fotografía original en formato rectangular, sin arco.
- Paleta fucsia de baja tonalidad, rosa suave, crema y detalles dorados.
- Diseño adaptable a celulares y computadoras.
- Navegación entre varias páginas y botón para compartir la invitación.

## Páginas
- `index.html`: portada, fotografía y mensaje principal.
- `misa.html`: fecha, hora y lugar de la misa.
- `compartir.html`: dirección del encuentro, transporte y sorpresa.
- `detalles.html`: código de vestimenta y mensaje final.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub, por ejemplo `invitacion-belen-jazmin`.
2. Sube todos los archivos y la carpeta `assets`, manteniendo su estructura.
3. Entra en **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
6. Espera a que GitHub publique el sitio. La dirección aparecerá en la sección Pages.

La URL tendrá una estructura similar a `https://TU-USUARIO.github.io/invitacion-belen-jazmin/`.
